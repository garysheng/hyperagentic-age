# The Hyperagentic Age: the canon file

> **THE PROPERTIES REGISTRY AND CROSSOVER LOG BELOW ARE GENERATED. DO NOT HAND-EDIT THEM.**
> Their rows are projected from one file per record: `canon/properties/<id>.json` and
> `canon/crossovers/<id>.json`. Add a record, then run
> `python3 -m agenticstory.cli build-canon <universe>`. If you already hand-appended a row,
> `build-canon --adopt` ingests it instead of dropping it. Every other section of this file is
> hand-authored.

The universe bible for the HYPERAGENTIC AGE narrative universe: warm-editorial picture books
about the agentic era — what agents make possible, what stays human, and the people (real and
fictional) living the transition. Register: warm editorial ink-and-wash, anchored on the
content-neutral swatch. Mark: "A HYPERAGENTIC AGE story". Real people render as stylized
editorial likeness in spreads, with hyper-real register-neutral reference matrices (SPEC v0.38).
