# Lineage: the sniped design

These are the ORIGINAL plates from the christofuturism universe's
`christofuturist-spatial-lenses`, copied here on 2026-08-11 when Gary asked to
snipe that design into this universe.

**They are a design record, not render references. Never pass them to a
generator.** They are photoreal, and `photoreal` is an explicit rejected pole of
this universe, so passing one as a reference pulls every render off-register.

What was sniped is the DESIGN, and it lives in the entity's `invariants`: clear
translucent champagne acetate, slim old-gold inlay, faint smoke-gold tint with
the eyes visible, elegant modern wayfarer shape. The in-register masters shot
from those invariants are the ones beside this folder, and those are what render.
