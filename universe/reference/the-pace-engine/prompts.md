# the-pace-engine — generation prompts

Register anchor (`reference/style/warm-editorial-neutral/refs/warm-editorial-swatch.png`) is passed FIRST as the style anchor on every shot. warm editorial ink-and-wash; never neon, 3D/CGI/Pixar, glossy plastic, HUD/arc-reactor comic vocabulary, neo-comic.

Authored 2026-08-09 (cast phase of the-goldilocks-pace). Bodies composed from the entity by compose_prompts.py, then framing pins added by the author. Every prompt leads with the register anchor, bakes the rejected poles as negatives, states the invariants verbatim, and contains no legible text (the dial glyphs are pictograms, not lettering).

### SHOOT ORDER

1. **`blueprint` is CODE-DRAWN, not prompted. Build it BEFORE you shoot anything else**, with `abu elevation` or `abu massing` from a declarative spec in `canon/blueprints/`, so the geometry is a number rather than a guess. Once it is on disk with its recipe, `shoot-references` never regenerates it and passes it as conditioning to EVERY shot automatically (SPEC 12), and its section below is never used. The section is only the fallback for an object with no fixed geometry, and it is what you will get by default if you skip this step.
2. **`master` is the seed** and the plate the human blesses. Shoot it with `--shoot-seed`, look at it, then `--bless-seed master`.
3. **Every state chains off `master`, never off a sibling state.** Pass `--star`. States differ in light, weather, season, or the presence of something, and a reference image outranks any negative: chained serially, one state's night walks into the next state's noon.

### WHAT MUST NOT DRIFT

Geometry in numbers, identical in every state: body 0.95 m tall on a 0.10 m base (waist-high to a 1.7 m adult), body 1.0 m wide, ONE circular dial of 0.5 m diameter (HALF the body width) centered on top and tilted up toward the viewer, a single bold needle pivoting from the dial's center, a small snail mark (about 1/8 dial diameter) at the dial's LEFT end and a small winged-block mark (same size) at the dial's RIGHT end. Every state fills the same footprint in the frame from the same three-quarter view. ONLY the needle's position, the glow, and the output change per state: steady = needle upright mid-dial + calm warm hum lines; roar = needle hard right + hot glow + motion-blurred output; cold = needle hard left + dark untouched engine, no glow. The same facts live on the entity as `structured.invariants`, so read-back checks the same wording.

Every heading below is a SHOT and every one above is level-3 prose. A level-2 heading that is not a shot is parsed as one and shot as garbage.
